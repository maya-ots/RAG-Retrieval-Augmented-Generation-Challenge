# Build a RAG (Retrieval-Augmented Generation) chatbot that can answer questions based on PDFs.
 - User asks a question (e.g. “How do I file a claim?”)

 - The bot searches inside PDFs

 - Returns the exact, relevant answer from the documents


* Backend (Python):
FastAPI
PyPDF (read PDFs)
Text chunking + overlap
Embeddings
FAISS (vector database)

* Frontend:
React chat widget (like a customer-support chat
